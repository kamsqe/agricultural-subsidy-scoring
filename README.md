# AgroScore — AI-скоринг сельхозсубсидий

**Decentrathon 5.0 | Трек: AI inDrive Gov | Кейс 2: Скоринг при подаче на субсидии**

> **Live Demo:** [agroscore.pages.dev](https://agroscore.pages.dev)

---

## Что это

Merit-based система ранжирования заявок на субсидии в животноводстве Казахстана. Заменяет принцип FIFO («кто первый подал») на data-driven оценку потенциального эффекта субсидии.

**Результат на данных:** при переключении с FIFO на merit-based ранжирование средний Impact Score вырастает на **+4.8**, а количество профинансированных мелких фермеров — на **+132** (симуляция на 2,854 заявках в очереди).

## Запуск

### 1. ML Pipeline (Python)

Генерирует обогащённый датасет и рассчитывает Impact Score для всех 36,651 заявок.

```bash
# Требования: Python 3.10+, openpyxl
pip install openpyxl

# Шаг 1: Feature engineering + merge с внешними данными
python pipeline/build_features.py
# → data/processed/enriched_applications.csv (36,651 × 67 столбцов)

# Шаг 2: Scoring
python pipeline/score.py
# → data/processed/scored_applications.json (36,651 заявок с баллами)
# → data/processed/scoring_summary.json (агрегаты для дашборда)
```

### 2. Frontend (Astro + React + Tailwind)

```bash
cd agroscore
npm install
npm run dev
# → http://localhost:4321
```

## Проблема

Субсидии на племенное животноводство (**139.3 млрд ₸/год**, 36,651 заявок) распределяются по FIFO — Пункт 21 Правил субсидирования.

| Проблема | Данные |
|----------|--------|
| Региональная лотерея | 0% отказов в Павлодаре vs 56% в Алматинской обл. |
| Retry-отказы | 30% заявок — повторные подачи одного фермера |
| Монополизация | Тюлькубасский район: 86% бюджета одному получателю |
| Бюджетный дефицит | Акмолинская обл.: 50.7% одобренных заявок ждут бюджет |
| Ceiling effect | Все видимые признаки объясняют лишь 31% причин отказа |

---

## Решение: Impact Score

Формульный (не black-box) скоринг из 5 компонентов:

| Компонент | Вес | Что измеряет |
|-----------|-----|-------------|
| **Strategic Alignment** | 20% | Соответствие приоритетам АПК 2021-2030 |
| **Fairness Factor** | 20% | Справедливость распределения, антимонополия |
| **Regional Need** | 20% | Бюджетный дефицит, потребность региона |
| **Efficiency Potential** | 20% | История заявок, репутация района |
| **Fraud Risk** | −10% | Штраф за аномалии (аутлайеры, круглые суммы) |

**Результаты на данных:**

| Метрика | Значение |
|---------|----------|
| Диапазон баллов | 35.9 — 69.8 |
| Средний балл | 57.6 |
| Gini (по районам) | 0.648 |
| Заявок с высоким fraud-риском | 14 (0.04%) |
| FIFO → Merit: прирост балла | +4.8 |
| FIFO → Merit: мелких фермеров | +132 |

## Данные

### Основной датасет (предоставлен)
- **36,651 заявок** за 2025 год из subsidy.plem.kz (ГИСС)
- 18 областей, 192 района, 46 типов субсидий
- Обогащён до **67 признаков** (см. ниже)

### Внешние источники (собраны самостоятельно)

| Источник | Что скачали | Как используем |
|----------|-------------|----------------|
| **stat.gov.kz** | 70 xlsx — поголовье скота, производство, фермерские хозяйства по регионам | 34 региональных признака (Strategic Alignment) |
| **subsidy.plem.kz API** | Бюджет по 18 областям (117.5 млрд ₸), воронки одобрения (436 строк), реестры 2019-2024 (429K записей) | Regional Need, Efficiency, исторический контекст |

### Обогащение данных

```
Исходный датасет (11 столбцов)
  + case-level dedup, retry detection
  + district/oblast агрегаты (reject rate, monopoly index, backlog)
  + stat.gov.kz: поголовье, производство, размер ферм (34 признака)
  + plem.kz: бюджет, число заявителей, воронки одобрения
  = 67 столбцов на заявку
```

Pipeline: `pipeline/build_features.py` → `pipeline/score.py`

## Ограничения

1. **69% причин отказа невидимы** — качество документов, решения инспектора, автоматические проверки ГИСС
2. **Веса не калиброваны эмпирически** — текущие веса = экспертная оценка на основе анализа данных
3. **Нет farmer ID** — используем прокси (район + тип + сумма) для retry-detection
4. **Инструмент для комиссии, не замена** — ТЗ требует «помощь эксперту», не автономное решение
5. **Нет данных о результатах** — не знаем, кто эффективно использовал субсидию
