## 🎯 Краткое описание

Merit-based система ранжирования сельхозпроизводителей для оптимального распределения субсидий в животноводстве Казахстана. Заменяет принцип "кто первый подал" (FIFO) на data-driven оценку потенциального эффекта субсидии.

## 💡 Проблема

Государственные субсидии на животноводство (**139 млрд ₸/год**, 36,000+ заявок) распределяются по принципу FIFO — кто первый подал, тот и получил. 

**Результат:**
- Топ-10 районов забирают **35.6% бюджета**
- Одинаковые фермеры: **0% reject** в Павлодаре vs **56%** в Алматы
- **65% отказов** — повторные подачи одного фермера

---

## ✅ Решение

Трёхслойная scoring-система:

1. **Pre-Check** — проверка заявки ДО подачи (rule-based)
2. **Impact Score** — ранжирование по 6 компонентам
3. **Anti-Fraud Layer** — выявление аномалий

**What-If симулятор** позволяет комиссии сравнивать сценарии: FIFO vs Merit-based.
