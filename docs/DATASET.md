## 2. Внешние источники (собраны самостоятельно)

### stat.gov.kz — региональная статистика

**Скрипт:** `data/external/analyze_stat_gov.py`
**Файлы:** `data/external/stat_gov_kz/` (70 xlsx)
**Выход:** `data/external/regional_features.csv` — 20 регионов × 34 признака

| Категория | Файлы | Что содержит |
|-----------|-------|-------------|
| Поголовье по регионам | element_458518.xlsx (12 листов) | КРС, овцы, козы, лошади, верблюды, свиньи, птица, молоко, мясо — 1990-2024, 20 регионов |
| Размер ферм | element_440925, 440926 | Распределение ферм по размеру (мелкие/средние/крупные) по регионам |
| Месячная динамика | elements 8125-8131 | Ежемесячное поголовье 2019-2025 по регионам |

**34 признака на регион:** поголовье по видам (2020-2024), доля мелких/средних ферм, месячные тренды (YoY %), производство молока и мяса.

## 3. Обогащённый датасет

**Pipeline:** `pipeline/build_features.py`
**Выход:** `data/processed/enriched_applications.csv` — 36,651 строк × 67 столбцов

### Производные признаки (из основного датасета)

| Признак | Формула | Описание |
|---------|---------|----------|
| `volume` | amount / norm | Объём продукции (единицы зависят от типа!) |
| `subsidy_code` | app_number[:5] | Код типа субсидии |
| `category` | lookup by code | acquisition / production / breeding / emergency / other |
| `retry_count` | case-level dedup | Номер попытки (0 = первая) |
| `is_retry` | retry_count > 0 | Повторная подача |
| `month`, `day_of_week`, `hour` | из даты | Временные признаки |

### Агрегатные признаки (из основного датасета)

| Признак | Уровень | Описание |
|---------|---------|----------|
| `district_reject_rate` | район | Доля отклонённых заявок |
| `district_top1_share` | район | Доля крупнейшего получателя (monopoly index) |
| `district_median_amount` | район | Медианная сумма заявки |
| `amount_vs_median` | заявка | Сумма / медиана района |
| `oblast_backlog_ratio` | область | Доля заявок в статусе «ожидание бюджета» |
| `oblast_execution_rate` | область | Доля исполненных заявок |
| `type_reject_rate` | тип субсидии | Доля отклонённых по типу |
| `is_round_million` | заявка | Сумма кратна 1 млн |
| `is_weekend` | заявка | Подача в выходной |

### Внешние признаки (из stat.gov.kz)

26 признаков с префиксом `reg_`: поголовье по видам, производство молока и мяса, доля мелких ферм, месячные тренды.

### Внешние признаки (из plem.kz)

| Признак | Описание |
|---------|----------|
| `oblast_budget` | Бюджет области (тенге) |
| `oblast_applicants` | Число активных заявителей |
| `oblast_enterprises` | Число зарегистрированных предприятий |
| `budget_per_applicant` | Бюджет / число заявителей |
| `oblast_approval_rate` | Доля одобренных (из внешней воронки) |
| `oblast_execution_rate_ext` | Доля исполненных (из внешней воронки) |

**Сравнивать production_volume между разными нормативами нельзя!** Единицы: головы (150K-260K ₸/голова), кг (20-300 ₸/кг), дозы (10K ₸/доза).
