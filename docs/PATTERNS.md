# Паттерны в датасете: 11 раундов анализа

Верифицированные находки из 36,651 заявок на субсидии животноводства (2025 год, subsidy.plem.kz). Каждый паттерн прошёл stress-test и контроль по confounders.

---

## Paradigm Shift: Application-level vs Case-level

**Главное открытие.** 65% отказов — повторные подачи одного фермера (одинаковый район + тип + сумма).

| Метрика | Application-level | Case-level |
|---|---|---|
| Единиц | 36,651 заявок | 23,851 кейсов |
| Reject rate | **9.2%** | **3.7%** |
| Одобрено с 1 попытки | — | 88.1% |
| Одобрено после retry | — | 5.8% |
| Никогда не одобрено | — | 3.6% |

Реальная проблема — не "кто получает", а **friction** (фермеры тратят месяцы на retry) и **FIFO** (кто первый — тот и получил).

## Верифицированные паттерны

### ✅ Что реально работает (Information Gain рейтинг)

```
district              : 0.058 bits  ███████████    (#1)
oblast                : 0.041 bits  ████████       (#2)
subsidy_code          : 0.032 bits  ██████         (#3)
month                 : 0.007 bits  █              (#4)
всё остальное         : <0.005 bits                (шум)
```

**Все фичи вместе объясняют 31% rejection variance.** 69% — невидимо (документы, автопроверки ГИСС, решение инспектора).

### ✅ Oblast strictness — два разных типа

| Тип | Пример | Механизм |
|---|---|---|
| **Бюджетный дефицит** | Акмолинская (100% reject апр-окт, потом 6%) | Деньги кончились |
| **Строгая проверка** | Жамбылская (стабильные 20-30% весь год) | Инспектор строгий |
| **Мягкий** | Павлодар (0.3%), Актюбинск (0.7%) | Одобряют почти всё |

Verified: для одного и того же типа субсидии 00400 (покупка КРС): Павлодар = 0% reject, Алматы = 50%.

### ✅ Simpson's Paradox — нельзя одну модель для всех

| Тип субсидии | Код | Reject | Характер |
|---|---|---|---|
| Селекционная работа | 01300 | 0.8% | Автоодобрение |
| Товарное поголовье | 01200 | 1.4% | Автоодобрение |
| Покупка быков | 00700 | 10.2% | Реальная проверка |
| Покупка КРС | 00400 | 14.9% | Реальная проверка |
| Корма (шерсть) | 03900 | 36.1% | Строгая проверка |

При смешивании типов возникают ложные паттерны (средние хозяйства = чаще reject — артефакт, исчезает при контроле по типу).

### ✅ Бюджетные волны

```
Месяц | Reject% | Бюджет (кумулятивный)
  4   |   4.4%  |   43 млрд   ← минимум (новый транш)
  8   |  13.3%  |   71 млрд   ← пик (бюджет исчерпан)
```

### ✅ "Сформировано поручение" = живая очередь

2,854 заявки одобрены по содержанию, но ждут денег. Акмолинская: 50.7% всех заявок в этом статусе.

### ✅ Монополизация субсидий

- Тюлькубасский район: 86% бюджета → одна заявка
- Казталовский район: макс 0.9% → равномерно по 1,450 фермерам
- Топ-10 районов = 35.6% всех субсидий

### ✅ Региональная специализация

| Область | Специализация | Индекс |
|---|---|---|
| Мангистау | Коневодство + верблюды | 9.1-9.6x |
| Алматинская | Птицеводство | 4.6x |
| Шымкент | Пчеловодство | 20.4x |
| Караганда | Свиноводство | 7.2x |

### ✅ Batch processing отказов

Жуалынский район: 23.05.2025 — 12 из 12 заявок отклонены (100%). Инспекторы обрабатывают пакетами.

## Опровергнутые паттерны

| Утверждение | Вердикт | Причина |
|---|---|---|
| "Средние хозяйства отклоняют чаще" | ❌ Simpson's paradox | Исчезает при контроле по типу |
| "Ночные подачи одобряют чаще" | ❌ Часовые пояса | Мангистау UTC+5, система UTC+6 |
| "Round volume = ниже reject" | ❌ Артефакт молока | Только для кода 02000 |
| "Day 23-25 = пик отказов" | ⚠️ Только для молока | 22.7% vs 11.8%, но не для других типов |
| "Outlier по сумме = риск" | ❌ Нет эффекта | 9.4% vs 9.2% |
| "Бедные районы = больше отказов" | ❌ Слабая связь | Q1=11.1% vs Q4=9.1% |
| "Поздние подачи внутри месяца = хуже" | ❌ Наоборот | 8.3% vs 9.3% |
| "Gini = предсказывает reject" | ❌ r=-0.14 | Слабая отрицательная |
