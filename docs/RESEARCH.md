### Процесс подачи заявки (детально)

```
День 0: Фермер
├── Входит в ГИСС через ЭЦП
├── Выбирает тип субсидии
├── Заполняет форму:
│   ├── Количество голов / объём продукции
│   ├── Прикрепляет документы (сканы)
│   └── Подписывает ЭЦП
└── Отправляет заявку

День 0-2: Автоматическая проверка
├── Валидация БИН/ИИН
├── Проверка в ИСЖ (скот зарегистрирован?)
├── Проверка в ИБСПР (племенной статус?)
├── Проверка в ГЗК (земля есть?)
└── Проверка в КГД (нет задолженности?)

День 1-2: Инспектор МИО
├── Проверяет документы вручную
├── Проверяет критерии Приложения 2
├── Принимает решение:
│   ├── ✅ Одобрить → в реестр ожидания
│   ├── ❌ Отклонить → с указанием причины
│   └── ↩️ Вернуть на доработку
└── Подписывает ЭЦП

День 2+: Ожидание бюджета
├── Заявка в реестре одобренных
├── Ранжирование по дате/времени (FIFO)
├── При наличии бюджета → выплата
└── При отсутствии → статус "Сформировано поручение"
```

### Основания для отказа (из данных)

Анализ 2,909 отклонённых заявок показал:

## Проблемы системы (подтверждено данными)

### 1. FIFO вместо merit-based

**Источник:** Пункт 21 Правил субсидирования

> "Выплата субсидий осуществляется в порядке очерёдности поступления заявок"

**Последствия:**
- Фермеры соревнуются в скорости подачи, не в качестве
- Нет стимула для эффективного использования субсидий
- Крупные хозяйства с ресурсами подают быстрее

**Данные:**
- Январь: 4,234 заявки (пик — начало года)
- Август: 13.3% reject (бюджет исчерпан)

### 2. Retry-отказы (65% всех отказов)

**Открытие:** Case-level анализ показал, что большинство отказов — повторные подачи.

```
Application-level: 36,651 заявок, 2,909 отказов (9.2%)
Case-level:        23,851 кейсов,   881 отказов (3.7%)

Разница: 2,028 отказов = retry одного фермера
```

**Причины retry:**
- Фермер не знает причину отказа до подачи
- Нет Pre-Check системы
- Исправляет и подаёт снова (иногда 5-7 раз)

**Стоимость:**
- Время фермера: месяцы ожидания
- Время инспектора: ~1,500 лишних проверок/год
- Frustration: негативный опыт с госуслугами

### 3. Бюджетный дефицит (региональный)

**Данные по Акмолинской области:**

| Статус | Количество | % |
|---|---|---|
| Исполнена | 1,234 | 32.1% |
| Одобрена | 412 | 10.7% |
| **Сформировано поручение** | **1,951** | **50.7%** |
| Отклонена | 251 | 6.5% |

**Интерпретация:** 50.7% заявок одобрены, но ждут бюджет. Это не отказ — это очередь.

**Сравнение с другими областями:**

| Область | % в ожидании | Интерпретация |
|---|---|---|
| Акмолинская | 50.7% | Критический дефицит |
| Костанайская | 28.3% | Высокий дефицит |
| Павлодарская | 2.1% | Профицит |
| Актюбинская | 1.8% | Профицит |

### 4. Монополизация субсидий

**Кейс Тюлькубасского района:**

```
Всего субсидий в районе: 2.3 млрд тенге
Топ-1 получатель: 1.98 млрд тенге (86%)
Остальные 47 фермеров: 0.32 млрд тенге (14%)
```

### 5. Региональная лотерея

**Один и тот же тип субсидии (00400 — покупка КРС):**

| Область | Reject Rate | Интерпретация |
|---|---|---|
| Павлодарская | 0% | Одобряют всех |
| Актюбинская | 0.7% | Почти всех |
| Алматинская | 56% | Отклоняют больше половины |
| Жамбылская | 28% | Строгая проверка |

**Причины различий:**
- Разные инспекторы (субъективность)
- Разные бюджеты (дефицит vs профицит)
- Разные интерпретации правил

### 6. Неэффективность расходов

**Источник:** Высшая аудиторская палата (ВАП), отчёт 2023

> "По результатам аудита за 2022-2023 годы выявлено неэффективное использование бюджетных средств на сумму 66 млрд тенге"

**Проблемы по ВАП:**
- Субсидии получателям без реального производства
- Двойное субсидирование
- Отсутствие контроля результатов

## Международные аналоги

### USDA EQIP (США) — эталон merit-based системы

**Environmental Quality Incentives Program** — программа субсидирования фермеров на природоохранные практики.

#### Как работает

```
1. Фермер подаёт заявку с планом практик
2. Заявка оценивается по баллам:
   - National priorities (федеральные приоритеты)
   - State priorities (штатные приоритеты)
   - Local priorities (локальные приоритеты)
3. Заявки ранжируются по общему баллу
4. Финансируются сверху вниз, пока есть бюджет
5. Не прошедшие — в waitlist на следующий цикл
```

#### Критерии оценки (пример)

| Критерий | Макс. баллы | Описание |
|---|---|---|
| Environmental benefit | 50 | Польза для окружающей среды |
| Cost efficiency | 20 | Эффективность затрат |
| Producer commitment | 15 | Обязательства фермера |
| Underserved producer | 10 | Поддержка мелких/новых |
| Geographic priority | 5 | Приоритетные зоны |

#### Что можно адаптировать для КЗ

| EQIP практика | Адаптация для КЗ |
|---|---|
| Environmental benefit | → Strategic Alignment (соответствие Концепции АПК) |
| Cost efficiency | → Efficiency Potential (история, репутация района) |
| Underserved producer | → Fairness Factor (мелкие фермеры, монополизация) |
| Geographic priority | → Regional Need (бюджетный дефицит, специализация) |

### EU CAP (Европейский союз)

**Common Agricultural Policy** — крупнейшая программа субсидирования в мире (€55 млрд/год).

#### Эволюция подхода

| Период | Подход | Проблемы |
|---|---|---|
| 1962-2003 | Price support | Перепроизводство, торговые войны |
| 2003-2013 | Area-based payments | Платят за землю, не за результат |
| 2014-2020 | Greening | Слабый экологический эффект |
| 2021-2027 | **Result-based** | Платят за достижение целей |

#### Eco-schemes (новый подход)

```
Фермер выбирает eco-scheme:
├── Органическое земледелие → +€200/га
├── Сохранение биоразнообразия → +€150/га
├── Снижение пестицидов → +€100/га
└── Углеродное земледелие → +€250/га

Выплата = базовая + eco-scheme бонус
Контроль = спутниковый мониторинг (LPIS)
```

#### Что можно адаптировать

| EU практика | Адаптация для КЗ |
|---|---|
| Result-based payments | → Встречные обязательства (уже есть с 2025) |
| Eco-schemes | → Бонусы за племенную работу, переработку |
| LPIS мониторинг | → Интеграция со спутниковыми данными |

### OECD по Казахстану (2025)

**Источник:** OECD Agricultural Policy Monitoring and Evaluation 2025

#### Ключевые выводы

1. **Поддержка удвоена** — в 2024 КЗ достиг максимума по WTO (10% от валовой продукции)

2. **Смена модели** — субсидии теперь идут через производителей ресурсов:
   - Удобрения: субсидия производителю → скидка фермеру
   - Техника: субсидия лизинговой компании → льготный лизинг
   - Семена: субсидия семеноводам → дешёвые семена

3. **Встречные обязательства** — с 2025 фермер обязан:
   - Сохранить или увеличить объём производства
   - Отчитаться через ГИСС
   - Невыполнение 2 года → лишение права на субсидии

4. **Даму (кредиты):**
   - Гарантии до 85% залога
   - Субсидирование ставки (до 10% годовых)
   - Интеграция с ПКБ (для кредитов, не субсидий)

5. **Рекомендации OECD:**
   - Перейти от input subsidies к result-based
   - Усилить мониторинг результатов
   - Интегрировать данные (налоги, кредиты, производство)

## Про ПКБ и налоговую

### Текущее состояние

| Источник данных | Интеграция с ГИСС | Используется для |
|---|---|---|
| КГД (налоговая) | ✅ Есть | Проверка БИН, ЭСФ, задолженность |
| ПКБ (кредитное бюро) | ❌ Нет | Только для кредитов Даму |
| Банки | ❌ Нет | — |
| Статистика | ✅ Частично | Агрегаты по регионам |

### Что даёт интеграция с ПКБ (гипотетически)

| Данные ПКБ | Польза для скоринга |
|---|---|
| Кредитная история | Финансовая дисциплина фермера |
| Текущие кредиты | Долговая нагрузка |
| Просрочки | Риск невыполнения обязательств |
| Кредитный рейтинг | Общая надёжность |

### Что даёт интеграция с налоговой (уже есть)

| Данные КГД | Польза для скоринга |
|---|---|
| ЭСФ (электронные счета-фактуры) | Подтверждение объёмов продаж |
| Налоговая отчётность | Реальный оборот хозяйства |
| Задолженность | Блокирующий критерий |

### Наша позиция

**В текущем проекте:**
- Используем только данные из датасета (нет ПКБ, нет детальной налоговой)
- Строим scoring на доступных фичах (район, тип, объём, история)

**Как "дальнейший шаг":**
- Предлагаем интеграцию с ПКБ для Efficiency Potential
- Предлагаем глубокую интеграцию с КГД для верификации объёмов
- Это требует изменений в законодательстве и API

### Ключевые международные практики

#### Feeding America Choice System

Система распределения продовольственной помощи через "рынок" с виртуальной валютой:
- Банки еды получают "shares" пропорционально бедности региона
- Торгуются за продукты на аукционе
- Revealed preferences вместо навязанных приоритетов

**Применение:** Идея "shares" для региональных квот.

#### Quadratic Voting / Funding

Механизм, где влияние растёт как корень из вклада:
- Предотвращает доминирование крупных игроков
- Стимулирует широкую поддержку

**Применение:** Для будущего governance субсидий.

#### Rawlsian Maximin

Принцип: максимизировать благосостояние наименее обеспеченных.

**Применение:** Vulnerability Index в scoring.
